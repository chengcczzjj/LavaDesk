# 伴侣智能体桌面控制设计

> 资料角色（2026-09-26，09-27 补充 §8）：描述已实现的聊天智能体桌面控制链路与边界，按源码核对。当前能力与验收缺口以 [项目状态](../TempFile/文档资料/project-status.md) 为准；开发规则见 [AGENTS.md](../AGENTS.md)。
> 与既有设计的关系：继承 [AI 桌面编排设计](小组件/AI桌面编排系统设计.md) 的风险分级与“先预览后应用”，以及 [轻量桌面助手规格](../TempFile/文档资料/记忆系统/local-folder-agent-development-guide.md) 的伴侣优先定位；文件/命令工作区 Agent 的审批与 checkpoint 不变。

## 1. 目标

说一句话就能把桌面调成想要的样子，说清做了什么，并且一键能撤回。三条硬约束：

- 桌面类工具每轮都给模型，不再靠关键词决定“这轮能不能做”。
- 需要确认的动作由界面执行确认，模型无法自己声明“用户已同意”。
- 改动桌面的动作都有回执；能撤回的给撤回，不能撤回的明确标注。

## 2. 分层

```
入口层   主界面聊天 │ 桌面快捷对话（全局热键 / 点桌宠 / 托盘） │ 提醒调度
编排层   上下文 = 人设 + 工具守则（固定前缀） + 当前时间/记忆/桌面现状/最近操作（动态尾部）
         模型 ⇄ 托管工具集（策略 → 挂起确认 → 快照 → 执行 → 回执）
能力层   壁纸 · 组件 · 场景 · 桌面模式 · 应用 · 系统 · 白噪音 · 桌宠 · 提醒 · 附件 · 撤回
策略层   actionPolicy：auto / confirm（可记住）/ deny
回执层   actionJournal：前后状态差异 → 撤回、回执条、下一轮摘要
```

## 3. 工具暴露

- 常驻：companion、memory、widget、desktop 四类（当前 29 个），按清单顺序发送，前缀在轮次之间保持一致。
- 门控：桌面编排草案工具在出现“布置/极简/专注/夜间/模式/场景”等意图或近期用过时加入；文件、文档、命令工具仍需选择工作文件夹并按意图加入；附件工具只在本会话有附件时加入。
- 系统提示顺序：人设与伴侣基调 → 工具守则 → 当前时间、召回记忆、【桌面现状】、【最近的桌面操作】。时间放尾部，避免每轮打断提供商的前缀缓存。

## 4. 新能力

| 工具 | 复用的现有链路 | 默认策略 |
| --- | --- | --- |
| `wallpaper` 列表/切换/随机/音量速度缩放/多屏模式/在线搜索安装 | wallpaperIpc 的 `*ForTool` 导出（同一变更队列与资源占用锁） | 自动，可撤回；换壁纸会切到该壁纸自己的组件布局 |

## 5. 确认与撤回语义

- 确认：工具调用在包装层挂起，界面收到确认卡；用户同意后以原参数执行同一调用，结果回到同一轮推理；拒绝/超时（120 秒）返回 `declined: true`，不算工具失败。没有界面通道的后台运行（自动化）一律按未同意处理。
- 快照：带 `journal` 标记的工具串行执行，前后读取壁纸布局、壁纸设置与组件列表。组件按单个 id 差异撤回，不覆盖之后用户的其他改动；壁纸切换后组件命名空间整体切换，不计为组件改动。
- 不可撤回：删除图标类组件（涉及真实文件移回桌面）、打开应用、系统音量/媒体键、截屏。日志只在内存保存最近 60 条，应用重启后旧回执的撤回会提示已过期。
- 撤回前校验：壁纸在之后又被换过时不强行改回；组件属于另一张壁纸时提示先切回。

## 6. 快捷对话与桌宠

- 全局热键默认 `Ctrl+Alt+Space`（设置页可改或关闭）；点击桌面桌宠、托盘“快捷对话”也可打开。窗口靠近桌宠或任务栏角落，Esc 收起。
- 使用独立的“桌面快聊”会话；“在主界面继续”把同一会话交给主聊天页。窗口收起后到达的回复由桌宠气泡说出；需要确认时会重新弹出窗口。
- 快捷对话窗口是独立的 `quick-chat` 角色：preload 只暴露聊天相关 API，主进程按窗口角色校验。
- 桌宠跟随智能体阶段（思考/检索/整理/出错），阶段 45 秒自动过期；场景应用后按模板表情反馈。

## 7. 验证

- `npm.cmd test`：`tests/companion-agent.test.mjs` 覆盖结果口径、差异撤回、快照格式、应用搜索、提醒调度、Markdown、路由常驻、托管执行（确认挂起/回执/缓存失效）、撤回与提醒循环行为，以及 87 句中文指令都能触达所需工具。
- `npm.cmd run test:electron:smoke`：新增 quick-chat 组，用生产渲染器与沙箱 preload 验证历史、发送、确认卡、撤回。
- `npm.cmd run eval:companion`：配置 `EVAL_API_KEY`、`EVAL_BASE_URL`、`EVAL_MODEL`（可选 `EVAL_PROVIDER`）后，用真实模型统计 87 句的工具选择正确率，目标 ≥ 90%；未配置时只做离线装载检查。不属于标准测试。
- 第二轮：`tests/companion-ux.test.mjs` 覆盖回执状态、授权收回、热键录制、系统监控计算与粘贴/拖入副本；quick-chat 冒烟组增加过期回执、↑ 找回上一句与拖入文件以字节到达主进程。
- 仍需 Windows 实机验收：全局热键冲突、`SendInput` 媒体/音量键、开始菜单索引与应用唤起、截屏权限、系统通知与桌宠气泡、快捷对话窗口的层级与多显示器落位。

## 8. 第二轮交互升级（2026-09-27）

- **确认卡**：焦点默认在“好的”，Enter 同意、Esc 拒绝；底部倒计时条随剩余时间收缩，最后 30 秒才显示秒数；作答后按钮锁定并显示“收到，马上做 / 好，不做了”，防止重复提交。“以后都直接做”的授权可在设置 → 伴侣与快捷对话 →“不再询问的操作”逐条或全部收回。
- **回执**：历史回执按操作日志实时查状态（`chat:action-status`：active / undone / final / expired），重启后过期的回执显示时钟图标且不再给撤回按钮；通过对话撤回的回执在窗口重新获得焦点时同步为“已撤回”。一轮有 2 条以上可撤回改动时提供“全部撤回（N）”，由新到旧依次撤回，遇到失败即停。
- **快捷对话**：输入框随内容增高（约 5 行）；空输入时 ↑ 找回上一句；Ctrl+N 开新话题；Ctrl+V 粘贴截图、拖入文件直接成为附件（主聊天页同样支持拖放与粘贴）。
- **粘贴/拖入附件只传内容**：渲染层把文件字节交给主进程（`chat:attach-data`），主进程存副本到 `userData/chat-drops`（3 天后清理），图片必须通过文件头签名检查；渲染层永远拿不到、也不能提交文件路径，因此“只有用户挑的文件可读”的约束不变。原生选择器（`chat:attach-files`）仍是按路径授权的唯一入口。
- **热键设置**：点击按键框直接按组合键录制（按物理键位，Shift 单独不算），另有“恢复默认 / 关闭 / 打开”，被占用时提示未生效。
- **桌面组件**：
  - 桌宠：悬停上浮并提示“点我聊天”，点击先开心地回应再打开快捷对话；收起时说出的回复在气泡消失后留下红点，点开才消失。
  - 白噪音：定时关闭（15/30/60/90 分钟，到点后 4 秒内渐弱停止），按钮外圈显示剩余进度，播放时有呼吸波纹；`ambient_sound` 新增 `minutes` 参数，“放 30 分钟雨声助眠”一次完成；声音名称改为中文。
  - 快捷工具：快聊、截图（Windows 截图工具框选，其他系统保存全屏截图并定位文件）、便签（新建便利贴）、显示桌面、文件资源管理器、Windows 设置；执行中/成功/失败有即时反馈。移除了原占位的“重启”。
  - 系统监控：每 2 秒读取真实 CPU（按两次采样的时间差计算）与内存，CPU 最近 40 次采样折线，负载分三档配色，页面隐藏时暂停采集。
- **可点击组件不能是“被动组件”**：画布的被动组件名单决定 Windows 下光标经过时是否捕获鼠标。桌宠与快捷工具有了点击动作，已移出名单；系统监控仍为只读展示保持被动。
