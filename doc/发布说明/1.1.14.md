# LingyueDesk 1.1.14 发布说明

> 源码日期：2026-09-27；由 GitHub Actions（windows-latest）构建并发布
> 版本主题：聊天伙伴真正动手管桌面、桌面快捷对话、FlowWall 在线壁纸库、桌面组件升级

本版本包含 1.1.13 的全部内容，并在其上合并以下更新。

## 聊天伙伴能直接操作桌面

- 换壁纸、调壁纸音量/速度、多屏模式、在线壁纸搜索安装；保存并切换自己的“工作模式/休息模式”桌面；放白噪音；让桌宠做表情说话。
- 打开电脑上的应用（开始菜单、桌面快捷方式、Dock/图标收纳里的应用，以及记事本、计算器等系统工具）；显示桌面、打开常用系统设置页和常用文件夹、调音量、媒体播放暂停/切歌、截屏并看屏幕内容。
- 提醒：一次性、每天/工作日重复、天气早报、久坐提醒；可设安静时段，这段时间不主动打扰。
- 附件：在对话里添加图片、PDF、Word、Excel、文本，伙伴可以阅读；支持看图的模型直接看图，否则用本地文字识别。可以直接粘贴截图或把文件拖进对话框。
- 打开应用、截屏前会弹出确认卡（Enter 同意、Esc 拒绝，可选“以后都直接做”，并可在设置里收回）。换壁纸、加组件等桌面改动会留下回执，可以一键撤回、一轮多条改动可全部撤回，也可以直接说“撤回刚才的”。
- 回复按 Markdown 显示（列表、加粗、代码、表格）。伙伴每轮都知道当前桌面上有什么，以及刚刚做过哪些操作，“换回去”“再大一点”这类追问更可靠。
- 修正：一些工具失败时仍显示“已处理”；删除 Dock 的确认改由界面弹出，不再由模型自行决定；天气工具说明乱码。

## 桌面快捷对话

- 在任何地方按 `Ctrl+Alt+Space`，或点击桌面上的桌宠、托盘菜单“快捷对话”，弹出一个小对话窗口；设置里可以直接按键录制新热键或关闭。
- 输入框随内容增高，↑ 找回上一句，Ctrl+N 开新话题；可以“在主界面继续”同一段对话。
- 窗口收起后到达的回复由桌宠气泡说出，桌宠上会留一个红点直到你点开。

## FlowWall 在线壁纸库

- “壁纸资源”里新增 **FlowWall 发现**，在软件里直接浏览 [FlowWall](https://www.flowwall.ai/wallpaper/discover) 的精选动态壁纸与 4K 壁纸；登录状态只保存在灵月里。
- 在页面上点下载后，文件会自动检查（必须是真正的视频或图片）、加入“我的壁纸”并标注 FlowWall 来源；下载面板里可以一键设为壁纸。重复下载同一张会提示已存在，不会占用两份空间。
- 对伙伴说“去 FlowWall 逛逛”也能打开。

## 桌面组件

- 快捷工具：快聊、截图、便签、显示桌面、文件资源管理器、Windows 设置六个按钮都可以直接使用（移除了原来占位的“重启”）。
- 系统监控：显示真实的 CPU 与内存占用，CPU 最近变化折线，负载高时变色。
- 白噪音：可设 15/30/60/90 分钟后自动渐弱关闭，也可以对伙伴说“放 30 分钟雨声”；声音改为中文名称。
- 桌宠：悬停提示“点我聊天”，点击会先开心地回应再打开快捷对话。
- 修正：桌宠和快捷工具在 Windows 上点击会穿透到桌面的问题。

## 验证结果

- `npm test`：类型检查和只读 lint 通过；152 项单元/契约测试中，Linux 开发容器内 151 项通过。未通过的 1 项是桌面图标导入测试，依赖 Windows 路径分隔符，在未修改的源码上同样只在 Linux 失败；发布流程会在 Windows 上重新运行全部测试，失败即停止发布。
- `npm run test:electron:smoke`：协议沙箱、生产壁纸渲染器、显示工具栏、快捷对话、FlowWall 下载接管五组隔离 Electron 冒烟在 Xvfb 下通过。
- 开发容器内用本地替身站点和本地伪模型驱动真实应用，验证了 FlowWall 下载导入、快捷对话确认与撤回、组件与设置页交互。
- 发布流程在 Windows 上依次执行 `npm test`、Electron 冒烟和 `npm run build:win -- --publish never`；随后核对安装包、blockmap、latest.yml 以及安装包内的版本和各窗口入口（含快捷对话），先上传到草稿 Release，确认资产大小一致后才正式发布，最后从公开地址复核更新清单。以下构建校验由流程自动附加。

## 安装与更新

- 已安装 1.1.13 或更早版本：保持应用运行，自动更新会在后台下载 1.1.14，完成后点击通知或托盘菜单“重启并更新”。也可以在侧边栏更新按钮中手动检查。
- 手动安装：下载本 Release 中的 `lingyue-desk-1.1.14-setup.exe` 覆盖安装，用户数据保留在 userData，不受影响。
- 首次使用伙伴的桌面操作前，建议在设置 → 模型配置中确认所用模型支持工具调用；需要看图时选择支持图片理解的模型。

## 验收边界

本版本未在 Windows 实机上安装验收。开发环境无法访问 flowwall.ai，真实站点的下载按钮（是否需要登录/会员）未实测。全局热键冲突、`SendInput` 音量/媒体键、开始菜单应用唤起、系统截图工具、系统通知、快捷对话窗口的层级与多显示器落位、组件点击，以及 `lingyue://` 链接注册，仍需在目标设备上复测。安装包未使用 Windows 代码签名证书。
