# LavaDesk 1.2.0 发布说明

> 源码日期：2026-10-07
> 版本主题：灵月桌面改名 LavaDesk；便签拆分为独立软件 LavaNotes

## 改名为 LavaDesk

- 应用名、安装包、可执行文件和托盘名称统一为 LavaDesk（安装包 `LavaDesk-Setup-1.2.0.exe`，程序 `LavaDesk.exe`）。AI 伴侣的名字仍是“灵月”。
- 安装标识改为 `com.lavadesk.app`，数据目录改为 `%APPDATA%\LavaDesk`，自动更新来源改为 GitHub 仓库 `chengcczzjj/LavaDesk`，在线壁纸库改为 `chengcczzjj/LavaDesk-Wallpapers`。
- LavaDesk 会作为新应用安装，不覆盖旧版灵月桌面。

## 自动迁移旧数据

首次启动 LavaDesk 时：

1. 如旧版灵月桌面正在运行，先关闭它，以免数据库正在写入。
2. 把 `%APPDATA%\lingyue-desk` 复制到 `%APPDATA%\LavaDesk`：壁纸、组件布局、图标收纳与 Dock 里的桌面快捷方式、聊天记忆、模型与人设、各项设置。Chromium 缓存不复制。
3. 数据文件改用新名称（如 `lavadesk-config.json`、`lavadesk-memory.db`），配置里指向旧目录的路径改到新目录。
4. 取消旧版的开机启动，并提示是否卸载旧版。

旧数据目录不会被改动，可在确认 LavaDesk 一切正常后自行删除。迁移结果写在 `%APPDATA%\LavaDesk\.lavadesk-migration.json`；如果迁移失败，会提示原因并可重试。

## 便签改为独立软件 LavaNotes

- 桌面组件层的内置“自由便利贴”和软件内“任务便笺”工作台已移除。便签改由开源软件 [LavaNotes](https://github.com/chengcczzjj/LavaNotes) 提供：每张便签是一个透明纸张窗口，支持图片、表格、右下角缩放和待办；可以钉在桌面，显示桌面和最小化全部窗口时也不会收起。
- “小组件 > 便签”页面会检测 LavaNotes：已安装可直接新建便签、显示全部便签或打开便签管理；未安装则提供下载入口。
- AI 伴侣在你说“记一下……”“帮我写个便签”时，会用 LavaNotes 新建便签；未安装时会告诉你下载地址。
- 旧版便利贴不再显示在桌面上，也不会自动导入 LavaNotes；它们的内容在升级时按壁纸备份到数据目录的 `legacy-sticky-notes` 文件夹。

## 其他

- 桌面组件层去掉了只为便利贴服务的临时键盘焦点与点击置顶逻辑，其余组件的拖动、缩放与层级行为不变。
- 安装包仍未做代码签名。
