# 自由便利贴与任务工作台设计

> **已被替代（2026-10-07）**：本组件已从 LavaDesk 移除，便签改为独立开源软件 [LavaNotes](https://github.com/chengcczzjj/LavaNotes)（每张便签一个透明窗口，支持钉在桌面）。本文仅保留为历史设计参考。

> 重设计日期：2026-08-16
> 组件类型：`todo-board`  
> 核心原则：桌面是“真实便利贴”，软件内是“任务工作台”。

## 1. 问题与设计决策

旧版把新增、自动分组、计划/周记切换、统计和完整任务列表全部塞进一张 420×520 的桌面卡片，同时沿用普通组件的单实例、编辑模式移动、网格吸附和碰撞避让。它虽然功能完整，但不再像便利贴：占地大、信息密、不能自由叠放，完成任务也只是清单状态变化。

本版彻底拆开两个使用场景：

- **桌面**只负责提醒、快速改字、纸色/分类快捷设置、完成和空间摆放。
- **主应用**负责批量新增、日期/颜色/固定方式、自动分类、显隐、周复盘和完成归档。
- **AI 对话**操作与主应用相同的真实数据，不产生静态副本。

## 2. 同类产品调研结论

| 产品 | 关键能力 | 采用的启发 |
| --- | --- | --- |
| TickTick Desktop Sticky Notes | 任务可以脱离主应用成为桌面便笺，状态仍与任务数据互通 | 桌面形态和管理形态应分离，但必须共享同一任务 |
| Notezilla | 多便笺、任意摆放、提醒、皮肤和长期桌面常驻 | 多实例、材质差异和空间记忆是便利贴的基础价值 |
| Sticky Tasks | 即时新增、勾选、行内编辑，不复制重型项目管理器 | 桌面交互必须少而直接 |

来源：

- [TickTick Desktop Sticky Notes](https://help.ticktick.com/articles/7055780431722971136)，访问于 2026-08-16。
- [Notezilla](https://www.conceptworld.com/Notezilla)，访问于 2026-08-16。
- [Sticky Tasks](https://www.microsoft.com/en-pn/p/sticky-tasks/9p9tjzvf0h2j)，访问于 2026-08-16。

共同规律不是“在纸条上提供更多功能”，而是：记录足够快、位置足够自由、状态始终同步、复杂管理在另一层完成。

## 3. 产品模型

### 3.1 一张纸只做一件事

每个 `todo-board` 实例只保存一个可选任务，因此可以独立创建、移动、缩放、隐藏、完成、恢复和删除：

```ts
interface TodoWidgetConfig {
  version: 2
  task?: TodoTask
  color: 'butter' | 'rose' | 'mint' | 'sky' | 'lilac'
  paperStyle: 'tape' | 'pin' | 'plain'
  rotation: number
  tearRequestedAt?: number
}
```

空白实例允许用户先把纸贴到桌面，再直接写内容。任务仍保留标题、分类、截止时间、优先级、提醒和完成时间。

### 3.2 旧数据迁移

检测到 `version: 1` 的聚合任务板时：

1. 每一项旧任务展开为一张 v2 便利贴。
2. 第一项复用原实例 ID，其余实例使用稳定的序号后缀。
3. 新实例以 26×22px 小偏移错落叠放，尺寸统一为 220×190。
4. 已完成任务保留 `completedAt` 并设为隐藏，继续参与周统计和归档。
5. 空的旧任务板迁移为一张可直接编辑的空白便利贴。

## 4. 桌面体验

### 4.1 极简信息

桌面纸条只显示：

- 一条参考 Windows Sticky Notes 的极简顶栏，左侧只保留轻量分类/截止状态，右侧是一个省略号。
- 可点击编辑的任务文字。
- 左下角“完成并撕下”圆圈。
- 右下角自然折角，同时作为永久缩放把手。
- 纸胶带、图钉或自然贴三种固定方式。
- 省略号只展开五个纸色与工作、学习、生活、健康、其他五个分类，不进入主应用也能快速整理。

不显示任务列表、完成率、计划/周记标签、统计图、新增选项或重型管理入口。配色/分类浮层限制在纸内，窄尺寸色板自适应收紧，矮尺寸可在浮层内滚动。

### 4.2 自由摆放

- 默认尺寸 220×190，最小 150×130，最大 420×380。
- 排版同时读取容器宽度和高度：窄纸条收起分类文字，矮纸条隐藏元信息，大纸条增加留白和操作热区；字号不会只因“很宽但很矮”而异常放大。
- 无需进入全局组件编辑模式；按住纸面空白处或固定物即可立即拖动。
- 无需进入编辑模式；始终可以拖动右下折角缩放。
- 坐标按像素保存，不做 16px 网格吸附。
- 不显示吸附预览，不推开其他组件，便利贴之间允许完全重叠。
- 新增时主动以小偏移叠放，形成真实桌面纸堆，而不是自动寻找空白卡位。
- 只限制至少 42px 可见，允许贴近屏幕边缘但仍能抓回。
- 点击、拖动或缩放后的便利贴会进入纸堆最上层；层级使用独立 `stackOrder` 持久化，不依赖壁纸组件与全局 Dock 的数组合并顺序。

### 4.3 桌面直接输入与焦点层

Canvas 为了不抢占桌面键盘焦点，常态保持 `focusable: false`。便利贴进入文字编辑时使用独立的短生命周期输入会话：

1. 点击正文或空白占位后，通过受限 IPC 将 Canvas 临时设为可聚焦。
2. 主进程只聚焦 Canvas 和当前 textarea，不开启全局组件编辑模式、不最小化其他窗口、不改变置顶层级。
3. 输入期间保持鼠标命中，避免光标移出纸面后透明窗口中途穿透。
4. 失焦、Ctrl+Enter、Escape、桌面被其他应用遮挡或组件卸载时立即释放输入会话，恢复 `focusable: false` 和桌面层级。

全屏游戏退出后，Windows/DWM 可能保留可见的透明 Canvas，却丢失它的鼠标命中层。恢复链路因此不只修改穿透开关：

1. 全屏遮挡结束时先轻量刷新壁纸 WorkerW，再重绑 Canvas 的 DefView owner。
2. Canvas 使用 `showInactive + invalidate + alwaysOnTop -> HWND_BOTTOM` 的有界重组合，不抢焦点，最终仍位于桌面图标之上、普通应用之下。
3. 每次重组后强制重应用 Electron 鼠标穿透状态，避免原生样式缓存与真实 HWND 状态不一致。
4. 主进程原生命中知道光标位于便笺、但 140ms 内未收到 renderer 接管时，再执行一次交互自愈。只有命中 Canvas 或桌面 Shell 表面时允许自愈，普通应用窗口不会被错误抬高。

Canvas 空闲时以较低频率轮询原生命中区域；指针手势、文本输入、编辑模式或已命中组件时恢复高频轮询，减少常驻 CPU 唤醒而不牺牲拖动响应。

### 4.4 完成与撕除

点击完成后先写入 `done / completedAt / tearRequestedAt`，再播放约 540ms 的短撕除动画：

1. 一条细的不规则撕边从纸面左侧快速划过。
2. 撕边之前的纸面被逐步裁除，边界使用高低错落的 `clip-path` 模拟纤维断口。
3. 整张纸只平移约 2px、旋转约 0.4°，固定物就地淡出；不再向下掉落或模拟用力扯下。
4. 动画结束将实例设为 `enabled: false`，而不是删除。

这样桌面立刻变干净，主应用仍能统计和恢复历史。AI 完成任务时同样设置撕落请求；Canvas 收到同步后播放同一动画。

## 5. 主应用“便笺工作台”

软件内页面承载完整信息和管理能力：

### 5.1 快速创建

- 输入一件事，Ctrl+Enter 或按钮贴到桌面。
- 可选奶油黄、珊瑚粉、薄荷绿、雾霭蓝和丁香灰。
- 可选纸胶带、图钉和自然贴。
- 可选无日期、今天 21:00、明天 21:00和重要标记。
- 可直接添加空白便利贴。

### 5.2 进行中

- 按已逾期、今天、七天内、以后和无日期自动分组。
- 标题可行内修改；修改后重新自动分类。
- 单张显示/隐藏桌面、完成撕下或永久删除。
- 展示每张纸当前尺寸，便于确认桌面状态。

### 5.3 周复盘

- 支持本周和过去 52 周。
- 展示完成数、收尾率、活跃天和未收尾数。
- 七日柱状节奏、确定性自然语言总结和未收尾清单。
- 统计跨所有便利贴实例，包括隐藏和已经撕下的记录。

### 5.4 已撕下

- 按完成时间倒序归档。
- “重新贴回”会清除完成状态和撕落请求，并恢复桌面可见。
- 可以永久删除不再需要的历史。

## 6. 视觉方向

方向名为 **Torn Moments / 撕下这一刻**。

- 纸张采用细颗粒、轻微色差、硬纸边、折角和不完全对称圆角，不使用毛玻璃卡片。
- 每张纸保留 -4.5° 到 4.5° 的自然倾斜，纸胶带和图钉也有独立受力感。
- 整张便笺统一使用 Windows 系统 UI 字体链 `system-ui / Segoe UI / Microsoft YaHei UI`，中文正文常规字重、1.45 行高，不再使用手写体或楷体。
- 正文为唯一高对比信息；分类、日期和重要状态使用更小字号与中性色，层级参考 Windows Sticky Notes。
- 颜色用于区分纸张，而分类只使用一个小色点，避免信息重复编码。
- 管理页用“桌面纸堆预览 + 工作台”构图，视觉上明确桌面极简、软件内完整的分工。
- 动效只服务于贴入和撕下，不增加无意义的按钮漂浮效果。

## 7. AI 对话协议

`manage_todo_tasks` 跨所有 `todo-board` 实例聚合：

- `list`：返回任务、所属 `widgetId` 和桌面可见状态。
- `add`：每次创建一个新的便利贴实例。
- `update`：按 `taskId` 找到所属实例并修改。
- `complete`：保留实例，写入完成与撕落请求。
- `reopen`：清除完成状态并重新显示到桌面。
- `delete`：删除所属实例。
- `clear-completed`：永久删除所有完成实例。
- `weekly-summary`：跨可见、隐藏和完成实例汇总。

- [x] 不进入全局编辑模式即可直接拖动和右下角缩放。
- [x] 点击桌面便签正文可临时获得键盘焦点并直接输入，结束后自动归还焦点层。
- [x] 从全屏游戏/应用返回桌面后重建 Canvas owner、透明合成与鼠标穿透状态；缺失 renderer 命中时可限定在桌面表面自愈。
- [x] 窄、矮、默认和大尺寸分别重排元信息、正文、完成按钮与折角，不出现互相挤压。
- [x] 拖动、缩放使用像素坐标，不吸附、不避让，允许重叠。
- [x] 桌面只保留任务文字、轻量状态、完成和缩放，不出现周记与统计。
- [x] 桌面省略号可直接更改五种纸色和五个任务分类，选择实时写回实例配置。

- [x] 完成后播放 540ms 横向纤维撕除动画并隐藏，没有大幅下落，历史没有被删除。
- [x] 主应用支持创建、自动分组、显隐、行内修改、周复盘、归档、恢复和永久删除。
- [x] AI 跨所有实例完成增删改、完成、恢复、清理和周总结。
- [x] v1 聚合任务板可无损迁移为多张 v2 便利贴。
- [x] typecheck、lint、单元契约和生产构建通过。
